## Out of scope (per audit charter)

- **Missing Maia models (1200/1400/1600/1800):** Only odd-hundred models (1100/1300/1500/1700/1900) were available from lczerolens at commit time. `engineRouting.ts:16` and `maia.ts:16-22` correctly implement 200-Elo bucketing for the 5 available models. The 100-Elo resolution the spec describes cannot be satisfied without the missing .onnx files. Defer to user decision on sourcing or training the 4 missing models.
- **Anthropic `cache_control: { type: "ephemeral" }` on coaching system prompts:** `deepCoach.ts:206-214` and `llmCoach.ts:46-52` pass `system` as plain strings with no `cache_control` wrapper. All five system prompts are static and are prime caching candidates — every API call pays full input-token cost on the system prompt. Additionally, `deepCoach.ts:224-228` reads only `input_tokens`/`output_tokens`; `cache_creation_input_tokens` and `cache_read_input_tokens` are not tracked and `usdCost()` does not apply the $0.30/M cache-read rate. Implementing this requires Anthropic SDK changes and updated cost accounting; defer to user decision.
- **Piece sets, board themes, coord readability:** Owned by a separate worktree. No changes made to `BoardThemeProvider`, `PieceSetProvider`, or coord-related rendering. Any finding that would require touching board square painting or coord legibility is intentionally excluded from this audit's fix scope.
